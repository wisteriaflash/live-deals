# meituan-live-deals

个人向美团直播优惠提醒工具：巡检上海地区麦当劳、肯德基及常见快餐相关公开源，去重后推送到本人微信；支持手动投喂链接作为兜底。由本人审核后再转发微信群。

## Goals

- 几分钟到十几分钟内发现可用优惠摘要并推送到个人微信
- 主路径：源清单定时巡检；兜底：人工投喂链接/文本
- 不破解客户端、不绕过登录风控、不自动抢券/下单、不无人值守群发

## Constraints

- 城市：上海
- 品牌：麦当劳、肯德基、汉堡王、必胜客等常见快餐（可配置白名单）
- 推送：仅本人微信（默认 WxPusher）
- 数据：本地 SQLite；配置文件维护源清单
- 技术栈：Node.js 20+ + TypeScript 轻量栈（非 NestJS）；本机常驻服务，非对外网站

## Non-goals (v1)

- 抖音/支付宝渠道
- OCR 截图解析（可二期）
- 安卓 App（可二期；建议 Expo/RN，巡检仍在 Node 服务）
- 多用户账号体系
- 保证解析全部直播弹窗券

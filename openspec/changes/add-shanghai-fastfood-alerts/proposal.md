# Proposal: Add Shanghai Fast-Food Live Deal Alerts

## Intent

家人朋友需要及时得知美团直播中的麦当劳、肯德基等快餐优惠，但不希望直接对接不稳定的全自动进房抢券方案。本变更交付一个**本地常驻小工具**：定时巡检已配置的美团公开直播/活动源（上海），过滤品牌后推送到**本人微信**；本人审核后再转发群。另提供手动投喂入口作为巡检漏检时的兜底。

## Scope

**In**

- 可配置源清单（直播间/活动页 URL 或 ID）与品牌白名单
- 定时巡检公开可见摘要（默认间隔 5–10 分钟）
- 手动投喂链接/文本 → 同一套解析、去重、推送
- 本地 SQLite 存储与指纹去重
- 个人微信推送（WxPusher / PushPlus / 企微应用）
- 源连续失败时的维护提醒

**Out**

- 抖音、支付宝渠道
- 自动进房解析全部弹窗券、自动下单/抢券
- 直接往微信群灌消息
- OCR 截图（二期可选）
- 安卓 App（二期可选；Expo/RN，巡检仍在 Node 服务）
- 多租户/SaaS

## Approach

采用「巡检为主 + 投喂兜底」：采集层只消费公开页可稳定获取的信息；需登录或结构不可解析时标记 `needs_manual`，依赖投喂。过滤与推送与采集解耦，便于美团页面改版时只改 poller/parser。实现栈为 **Node.js 20+ + TypeScript 轻量服务**（`better-sqlite3`、本机 HTTP 投喂、WxPusher），便于维护并与后续 Expo/RN 客户端共享类型与规则。

## Impact

- 新建空仓库的首个行为能力（当前无主 specs）
- 运行时依赖：Node.js 本机常驻进程、微信推送通道 token、人工维护源清单
- 合规：不设计绕过风控或未授权大规模抓取；使用者需自行遵守美团服务条款
